## ⏳ Требует Unity Editor

### 4. Модель разделителя повернута на 180°
**Статус**: Требует ручного редактирования в Unity
**Что делать**:
1. Откройте префаб: `Assets/Prefabs/Builders/Splitter.prefab`
2. Найдите дочерний объект с моделью (обычно "Mesh" или "Model")
3. Установите Transform → Rotation → Y = 180
4. Сохраните префаб
