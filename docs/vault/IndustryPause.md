# IndustryPause

**Файл:** `Assets/Script/Core/UI/IndustryPause.cs`  
**Тип:** обычный класс, не MonoBehaviour. Живёт внутри [[GameManager]].

Меню паузы: продолжить, сохранить, настройки ([[SettingsHub]]), управление (сразу вкладка биндов), выход в меню с подтверждением.

Смена языка пересобирает UI (`Relocalize`).

Кнопка **«Персонаж»** — тот же экран внешности, что в главном меню ([[Avatar]]); превью работает и на паузе, изменения применяются к персонажу сразу.
