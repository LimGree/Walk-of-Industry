# Zipline — тросовая дорога

**Файл:** `Assets/Script/Core/Decor/Zipline.cs` (опора, отрисовка тросов, езда)
**Декор:** «Опора троса» `decor_zipline_post` в [[Decorations]] (покупка за рубины, установка за монеты), иконка `Resources/Decor/Icons/decor_zipline_post.png`.

- Каждая опора соединяется тросом с **ближайшей другой** опорой не дальше 40 клеток.
- Трос провисает на 6% длины посередине; тросы пересчитываются раз в секунду.
- **E у опоры** — едешь по тросу к её паре, висишь под тросом. **Пробел** — отцепиться.

Удобно на больших заводах, где ленты мешают ходить.
