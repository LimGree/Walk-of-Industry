# Economy

**Файл:** `Assets/Script/Core/Economy/Economy.cs`  
**Тип:** статический калькулятор, объектов нет

## Зачем нужен

Единственное место, где считаются деньги и глобальные множители скорости. Чтобы не размазывать баланс по десяткам ScriptableObject.

## Константы

- старт: **2500 монет, 10 рубинов**, 50 монет за рубин
- ленты: максимум 10 уровней, шестерёнки 1000 → 2 500 000, монеты 900 → 80 000 (в 5 раз дороже, чем раньше)
- `CraftTimeMul = 1.8` — все крафты дольше
- `ExtractTimeMul = 1.25` — добыча чуть медленнее

## Методы

### SellValue
Сначала старая шкала от `item.sellValue`. Сырьё экстрактора (`log`, `sand`, `stone`, `coal_ore`, `cooper_ore`, `iron_ore`, `sulfur`, `crude_oil`, `water`) остаётся как было. Остальное **÷ 5**, но не меньше **1** за штуку.

### BuildCost / UpgradeCost / RefundCoins
Цена постройки из карточки. Апгрейд ≈ `max(20, цена × 2)`. Снос возвращает **75%** (`PayRefund` из [[PlayerBuilder]] / выделения, не из загрузки сейва).

### RubyReward
Сколько рубинов за исследование, если в узле не проставлено вручную.

### BeltGearCost / BeltCoinCost / BeltMultiplier
Таблицы прокачки лент. Уровень 0 = ×1, уровень 1 = ×1.2, уровень 10 ≈ ×9.5.

### CraftNeed
`рецепт.craftTime × 1.8` — сколько «единиц прогресса» нужно станку.

### IsGear
Предмет с id `gear` / `gears` — шестерёнка для лент.
