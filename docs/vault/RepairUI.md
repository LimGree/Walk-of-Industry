# RepairUI

**Файл:** `Assets/Script/Core/UI/RepairUI.cs`  
**Тип:** компонент на [[GameManager]], UI Toolkit (`IndustryUi.OverlayPanel`)

Окно ремонта. E по сломанному станку открывает его вместо [[MachineUI]] (`RepairUI.TryOpen` в `Interact`). Мир **не на паузе**. Esc и пауза окно закрывают. Пока окно открыто, `WorldOverlayGate.IsOpen` глушит стройку, выделение, ходьбу и хотбар, чтобы клик в мини-игре не сносил здание.

Одна поломка — одна мини-игра. Какая, выбирается случайно при поломке (`BreakdownSystem.RollGame`). Там же закомментирован вариант с распределением по типу здания.

| # | Игра | Как |
|---|---|---|
| 0 | Провода | 4 цвета. Клик по левому концу, потом по правому того же цвета. Линии рисует `Painter2D` |
| 1 | Сигнал | Слайдер частоты. Сила ≥ 93% держится 1.5 с. Ошибок нет, только время |
| 2 | Двигатель | Зажать «ДЕРЖАТЬ», отпустить, когда стрелка в зелёной зоне. 3 раза, стрелка всё быстрее |
| 3 | Пример | Сложение и вычитание до 100, 3 примера. Enter — проверить |
| 4 | Капча | 50/50: 5 кривых символов **или** «выбери все картинки: предмет» 3×3 |

Ошибок не больше 3. На третьей ошибке списывается рубин и выпадает новая мини-игра. Дольше 45 с — рубин при успехе. Доплата за простой берётся из [[BreakdownSystem]]. Кнопка «Срочный ремонт» чинит сразу за рубины.

Если закрыть и снова открыть тот же станок, ошибки, таймер и игра сохраняются. Сбросить их так нельзя.

Кроме мини-игры ремонт (и «срочный») снимает **3–5% баланса** (`Economy.RepairFee`, процент растёт с балансом) — сумма в уведомлении «Работа: −N».
