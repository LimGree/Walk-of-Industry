# SettingsControls

**Файл:** `Assets/Script/Core/UI/SettingsControls.cs`

Строки настроек: слева название (+ `Describe` — серое пояснение), справа контрол.

- `Group` — заголовок группы с линией.
- `Toggle` — переключатель-«таблетка», клик по всей строке.
- `SliderRow` — слайдер + значение. Ключ локали «Название  {0} ед.»: до `{0}` — название, после — единица.
- `ChipRow` — сегменты выбора (больше 4 — строка переносится).
- `Dropdown`, `ActionRow` (кнопка справа).
- `Sync(row)` — перерисовать строку после изменения извне (например, после [[UiModal]]).

Используют [[SettingsHub]], [[MapSettingsUI]], [[GameAudio]].
