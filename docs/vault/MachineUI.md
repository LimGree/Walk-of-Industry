# MachineUI

**Файл:** `Assets/Script/Core/UI/MachineUI.cs`

Окно «открыл здание». Одно на игру (`Instance`).

В зависимости от типа:

- крафтер — список рецептов с поиском, прогресс, апгрейд (если у здания есть и исследование открыто);
- экстрактор — интервал и богатство;
- склад — сетка предметов;
- рука — фильтр;
- лаборатория — вкладки исследование / рецепты / ленты / статистика / **простой**.

T и E по лаборатории открывают одно и то же. T работает и без лаборатории в мире (`OpenLab`).

Вкладка исследований — граф [[ResearchTree]] (не список). Вкладка рецептов — [[RecipeCodex]]: только открытое, порядок как в дереве, поиск. Простой — список станков без входа / с забитым выходом; клик телепортирует, если в настройках карты разрешён телепорт. Над такими зданиями в мире жёлтый «!».
