# PlayerMovement

**Файл:** `Assets/Script/Core/Player/PlayerMovement.cs`  
**Тип:** компонент на капсуле игрока  
**Нужен** `CharacterController` на том же объекте

## Зачем нужен

Ходьба WASD, взгляд мышью, бег, прыжок, звуки шагов, зум камеры. При [[KeybindStore.BlocksGameplayInput]] / [[DevConsole]] ввод обнуляется, карта Player выключается.

Камера должна быть **дочерним объектом** игрока и перетащена в поле `cameraTransform`.

## Связи

[[KeybindStore]] · [[GameAudio]] · [[GameManager]] · [[WorldMapUI]] · [[MachineUI]] · [[InventoryUI]] · [[GridSystem]] (телепорт)

## Поля

| Поле | Роль |
|---|---|
| `canMove` / `canLook` | Можно ли ходить / крутить камеру (UI иногда выключает) |
| `walkSpeed` / `sprintSpeed` | Скорости |
| `jumpHeight` / `gravity` | Прыжок и падение |
| `mouseSensitivity` | Чувствительность мыши |
| `minPitch` / `maxPitch` | Как сильно можно смотреть вверх/вниз |
| `pitch` | Текущий наклон головы |
| `moveInput` / `lookInput` | Что нажато сейчас |
| `viewCam` / `baseFov` / `zoomStrength` | Зум: обычный угол обзора и сила приближения |

## Методы

### ApplySavedPose
Телепорт/загрузка: выключает контроллер (иначе он сопротивляется), ставит позицию и поворот, включает обратно.

### TeleportToCell
Из метки на карте: берёт центр клетки, лучом вниз ищет землю, вызывает `ApplySavedPose`.

### Start
Хватает CharacterController, прячет курсор, подписывается на WASD, мышь, бег, прыжок.

### Update
На паузе — возвращает обычный FOV и ничего не делает. Иначе: взгляд, ходьба, зум.

### HandleMouseLook
Мышь влево-вправо крутит **всё тело**. Мышь вверх-вниз крутит **только камеру** (иначе тело наклонялось бы как неваляшка).

### HandleMovement
Если на земле — обнуляет падение. Считает направление из WASD относительно взгляда. Бег быстрее. Шаги звучат реже, чем раньше (чтобы не дребезжать). Прыжок — формула «скорость вверх из высоты». Потом гравитация.

В океан не заходит (озёра можно). Если шаг попал в океан — откатывается и пробует скользить вдоль берега. Телепорт с карты с океана ставит на ближайшую сушу или озеро.

### HandleZoom
Пока зажато действие **Zoom** (по умолчанию C, см. [[KeybindStore]]):

- колесо меняет силу зума (пишется в PlayerPrefs);
- угол обзора камеры плавно едет к узкому.

Отпустил — плавно назад. Не работает, если открыта карта, станок, сумка или идёт переназначение клавиши.

### BindCamera / RestoreFov
Найти камеру. Вернуть заводской угол обзора (пауза, выключение скрипта).
