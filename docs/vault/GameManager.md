# GameManager

**Файл:** `Assets/Script/Core/GameManager.cs`  
**Тип:** компонент Unity (`MonoBehaviour`)  
**Один на всю игру:** да, `Instance`, не уничтожается при смене сцены (`DontDestroyOnLoad`)

## Зачем нужен

Это дежурный администратор игровой сцены. Он не крафтит и не ходит. Он:

- держит ссылки на инвентарь, строителя, исследования;
- включает паузу;
- при первом запуске **добавляет недостающие системы** на тот же объект (карта, кошелёк, ленты…);
- ловит клавишу паузы и закрывает окна по очереди, как стопку тарелок.

## Поля

| Поле | Роль |
|---|---|
| `Instance` | Глобальный «дай мне GameManager» |
| `playerInventory` | Ссылка на хотбар, ставится в инспекторе |
| `playerBuilder` | Ссылка на строителя |
| `researchSystem` | Ссылка на исследования |
| `isPaused` | Игра на паузе? |
| `inputActions` | Общий набор клавиш |
| `pauseUi` | Объект меню паузы (не компонент, обычный класс) |

## Методы

### Awake
Просыпается первым. Если уже есть другой GameManager — уничтожает себя (чтобы не было двух дирижёров). Иначе запоминает себя как `Instance` и говорит Unity: «не убивай меня при загрузке новой сцены».

Потом берёт общие клавиши из [[KeybindStore]]. Дальше по списку: если на этом же объекте нет карты / кошелька / … — **добавляет компонент**. Так игра не падает, даже если кто-то забыл перетащить скрипт в инспекторе.

В конце включает звук и применяет графические настройки.

### OnEnable / OnDisable
Подписывается на клавишу паузы и на событие «сцена загрузилась». Отписывается, когда объект выключают — чтобы не вызывать мёртвый код.

### OnSceneLoaded
Каждая новая сцена: ещё раз применить [[GameSettings]] (камера уже появилась, можно выставить дальность и туман).

### OnPausePerformed
Нажали Esc (или как переназначили паузу). Если идёт переназначение клавиши — игнор.

Дальше **закрывает верхнее открытое окно** и выходит:

1. сумка зданий  
2. магазин  
3. панель выделенных  
4. окно станка  
5. исследования  
6. меню постройки  
7. карта мира  

Если ничего из этого не открыто — переключает паузу.

### TogglePause / SetPaused
Ставит `isPaused`. Останавливает время (`Time.timeScale = 0`), глушит слух, играет звук паузы. Если пауза включилась — закрывает игровые окна и показывает [[IndustryPause]]. Если выключилась — прячет меню и возвращает фокус игре (курсор в захват).

### RestoreGameplayFocus
Прячет системный курсор, запирает его в окне — как в шутере. Нужно после закрытия UI.

### PrepareLeaveGameplay
Перед уходом в меню: снять паузу, остановить звуки паузы. [[MainMenu]] зовёт это, когда жмут «в меню».
