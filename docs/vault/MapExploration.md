# MapExploration

**Файл:** `Assets/Script/Core/Map/MapExploration.cs`

Туман исследования: байтовая маска клеток. Вокруг игрока кружок открывается каждый раз, когда он переходит клетку. Клетки под зданиями тоже открыты (фабрика видна).

Текстура тумана (тёмно-синяя с альфой) накладывается на [[WorldMapUI]]. Мягкий край кружка.

В сейве — биты Base64 + размеры (`exploredBits`, версия [[SaveData]] ≥ 5). Старые сейвы v4 считаются **полностью исследованными**, чтобы не закрыть уже построенный завод.

`HideUnexplored = false` в настройках — туман не рисуется (карта видна вся).
