# DevConsole

**Файлы:** `Assets/Script/Core/Debug/DevConsole.cs`, `DevCommands.cs`

Консоль разработчика. Тройное **Ё** / `` ` ``. Игра не на паузе. Карта `Player` выключается, ходьба и хоткеи молчат. Esc — закрыть.

Команды с `/`. Tab — автодополнение, стрелки — история. В строке ввода серое продолжение, над ней список вариантов (здания, жилы, биомы…).

`/timeskip ЧЧ:ММ:СС` — реальное время: монеты и предметы по `ProductionStats` сдаются в лабу (рубины нет), часы мира едут пропорционально длине суток.

`/conveer speed X` (`/conveyor`, `/belt`) — множитель скорости лент поверх уровня.

`/help` — список. `/money add N`, `/research skipall`, `/tp biome forest`, `/dump cell`, `/godsave` и остальные — в `DevCommands`.
