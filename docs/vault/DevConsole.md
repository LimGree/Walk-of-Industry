# DevConsole

**Файлы:** `Assets/Script/Core/Debug/DevConsole.cs`, `DevCommands.cs`

Консоль разработчика. Тройное **Ё** / `` ` ``. Игра не на паузе. Карта `Player` выключается, ходьба и хоткеи молчат. Esc — закрыть.
