# ContentValidator — проверка данных

**Файл:** `Assets/Script/Core/Editor/ContentValidator.cs` (только редактор)

Меню **Walk of Industry → Validate Content**. Ищет:

- входы станков, которые не сходятся с рецептами;
- рецепты без станка или без исследования;
- цену исследования из предметов, которые нельзя получить;
- id с пробелами.

Вызывается из [[AlphaBuild]] перед сборкой (ошибки — в лог, сборку не останавливает) и командой `/validate` ([[DevCommands]]). Как добавлять исследования — `ADDING_RESEARCH.md`.
