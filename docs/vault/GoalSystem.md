# GoalSystem — цели и подсказки

**Файл:** `Assets/Script/Core/Progress/GoalSystem.cs`. HUD — [[GoalsUI]]. План — `docs/План_обучения_и_прогрессии.md`.

Слои B и C обучения ([[Обучение]]): включаются, когда вводная глава [[TutorialSystem]] пройдена или пропущена.

## Вехи (слой B)

Активна одна, по порядку механик. Условия: исследовать узел, поставить N зданий, произвести N предметов (по [[ProductionStats]]). Награда — монеты.

assembler 1500 → gears 2000 → wire 2500 → logistics 3000 → constructor 4000 → sand 4000 → steel 5000 → power 5000 → motor 6000 → storage 6000 → fluids 8000 → chemistry 9000 → drones 9000 → computers 12000 → final (ИИ-модуль) 20000.

## Подсказки «в первый раз» (слой C)

Один раз на мир, с живыми клавишами из [[KeybindStore]]. Часть срабатывает, только если условие держится N секунд: нет рецепта, на вход пришёл не тот предмет, забит выход экстрактора, у конструктора только один из двух входов, подходит ночь, поломка, хотбар полон, пора копировать линию, трубы, переворот НПЗ, длинные ленты, список простоя. Прочитанные — в справочнике журнала (J).

## Отслеживание

Отслеживаемый предмет выбирается на [[ProductionMapUI]] — цепочка до руды с галочками («есть ли уже»: для сырья — экстрактор на жиле, для крафта — сделан хоть раз).
