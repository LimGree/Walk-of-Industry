# BuildingFootprintEditor

**Файл:** `Assets/Script/Core/Editor/BuildingFootprintEditor.cs`  
**Только редактор.**

В Scene View рисует клетки footprint выбранного здания и оверлей. Чтобы художнику/дизайнеру было видно, сколько места займёт станок.

Классы внутри: `BuildingFootprintSceneOverlay`, `BuildingBaseEditor`.

Не входит в билд игрока.
