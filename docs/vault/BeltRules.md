# BeltRules

**Файл:** `Assets/Script/Core/Logistics/BeltRules.cs`  
**Тип:** статическая таблица

## Зачем нужен

Правила тайла ленты. Форма, доворот меша и путь груза — одна таблица. Меш не задаёт путь.

Локальные оси клетки: **+Z = выход** (`transform.forward`), **+X = право**.

## Маска входов

Относительно выхода:

| Бит | Кто кормит клетку |
|---|---|
| `Back` | сосед сзади, его выход смотрит сюда |
| `Left` | сосед слева |
| `Right` | сосед справа |

Фронт никогда не вход.

## Форма

| Маска | Форма | Меш |
|---|---|---|
| нет / только зад | Straight | `prefab` |
| один бок | Corner | `cornerPrefab`, зеркало если вход слева |
| зад + один бок | Tee | `teePrefab`, extraYaw 270° справа / 90° слева; левый рукав — `teeMirrorMaterial` (Рисунок4_5 Mirror) |
| оба бока | Sides | `sidesPrefab`, extraYaw 90° |
| три входа | Triple | `triplePrefab`, extraYaw 90° |

## Путь груза

Не `StartPoint` / `EndPoint` на префабе.

- прямая: зад (−Z) → перед (+Z)
- угол и слияния: край входа → центр (t = 0.5) → перед
- два и больше входа: zipper — в центр по очереди (зад, лево, право), плотная главная не душит бок
