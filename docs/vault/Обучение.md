# Обучение

Сценарий первого входа в новый мир.

Код: `Assets/Script/Core/Tutorial/` — [[TutorialSystem]], [[TutorialUI]], [[TutorialFx]]. Сейв v9: `tutorialStep` / `tutorialFinished` / `tutorialSkipped` в [[SaveData]].

Связи: [[PlayerBuilder]] · [[PlayerInventory]] · [[InventoryUI]] · [[BuildSelectionController]] · [[Extractor]] · [[Conveyor]] · [[ResearchLab]] · [[ResearchSystem]] · [[ResearchUI]] · [[MachineUI]] · [[Smelter]] · [[WorldMapUI]] · [[WorldResourceScatterer]] · [[ResourceNode]] · [[KeybindStore]] · [[InputHintUI]] · [[SaveSystem]]

---

## Когда запускается

Только **первый вход в новый мир**. Не на загрузке сейва, не при повторном входе, если обучение уже пройдено или пропущено.

Если в мире уже есть `research_smelter` **и** хотя бы одна [[Smelter|плавильня]] с рецептом железного слитка — баннер не показываем.

Прохождение и пропуск писать в сейв мира ([[SaveSystem]] / [[SaveData]]), не в PlayerPrefs: у каждого мира своя история.

---

## Пропуск

На панелях Welcome и Farewell — кнопка «Пропустить» (всё обучение). Во время ходьбы курсор залочен:

- **F1** — пропустить обучение целиком (как кнопка);
- **F2** — только этот шаг. На приветствии = «Начать», на финале = «Играть».

Полный пропуск гасит обучение в этом мире навсегда, ничего не достраивает и не выдаёт. Здания, руда и монеты остаются как есть.

На долгом ожидании руды — только цель в углу и пропуск, без новых окон.

---

## Старт мира для обучения

Хотбар **пустой**. Extractor, Conveyor Belt и Research Lab лежат только в инвентаре зданий ([[InventoryUI]]).

Иначе шаг «перетащи в хотбар» пустой: сейчас [[PlayerInventory]] сам кладёт стартовые здания на панель (`FillEmptySlotsFromUnlocks`). На время обучения это выключить. После обучения автозаполнение новых зданий можно вернуть.

Режим стройки при входе в мир **выключен** ([[PlayerBuilder.isBuildMode]] = false, в `SampleScene` тоже). Включается по B.

Стартовый набор ([[ResearchSystem.startingBuildings]]): Extractor, Conveyor Belt, Research Lab. Рецептов на старте нет. Сборщик и плавильня — из дерева. Монеты: 2500 ([[Economy.StartingCoins]]).

---

## Что умеет игрок к концу

Ходить. Включить стройку. Собрать хотбар из инвентаря. Поставить [[Extractor]] на жилу. Понять: одна гора — один тип ([[WorldResourceScatterer]]), железо и медь на вершинах. Повернуть выход на ленту. Протянуть [[Conveyor]] зажатием. **Выделить рамкой, скопировать, вставить группу** ([[BuildSelectionController]]). Поставить [[ResearchLab]]. Запустить **Печь** до руды. Довезти 140 Iron Ore и 140 Cooper ore. Поставить плавильню. Исследовать железный слиток, выбрать рецепт. То же для меди копией.

Дальше сам: Сборщик (350 Iron Ingot) и **всё дерево до конца**.

## Подсветка

Одна подсветка за раз. Сняли шаг — сняли обводку.

| Тип | Как выглядит |
|---|---|
| Мир, жила | Пульс по клеткам нужной руды |
| Мир, здание | Обводка корпуса |
| Куда ставить | Пульс по свободным подходящим клеткам |
| Куда смотреть | Стрелка выхода на призраке / на здании ([[SocketArrow]]) |
| Куда вести ленту | Точки: выход → вход |
| Рамка / копия | Обводка выделенных зданий, затем призрак группы |
| UI | Кольцо/пульс на кнопке, карточке, слоте |

Клавиши в текстах — имя действия и дефолт в скобках. В реализации подставлять живой бинд из [[KeybindStore]].

| Действие | По умолчанию |
|---|---|
| Ходьба | WASD |
| Камера | мышь |
| Прыжок | Space |
| Бег | Left Ctrl |
| Строительство | B |
| Поставить / рамка / подтвердить вставку | ПКМ |
| Снести | ЛКМ |
| Повернуть | R |
| Хотбар | 1–9 / колесо |
| Пустой инструмент | 0 |
| Инвентарь зданий | I (только в стройке) |
| Карта | M (без выделенных зданий) |
| Перенос группы | M (когда есть выделение) |
| Редактирование | Tab |
| Копировать | C |
| Вставить | V |
| Сбросить выделение | X |
| Удалить выделенное | Backspace |
| Исследования | T |
| Взаимодействие | E |
| Пауза | Esc |

M — одно действие `MoveSelection`: карта в обычной стройке, перенос если есть выделение. См. [[WorldMapUI]] и [[BuildSelectionController]].

## Шаги

Каждый шаг: цель в углу + одна реплика. Дальше только по условию, не по таймеру. Ввод не блокируем, кроме панели шага 0.

Если игрок сделал шаг заранее — пропускаем.

### 0. Приветствие

Панель, ходьба ещё нет.

> Добро пожаловать в Walk of Industry. Ходишь сам, заводы работают даже за горизонтом.
>
> Сначала руда, лаборатория и первая глава. Потом плавильня — и дальше сам.
>
> [Начать]  [Пропустить]

**Подсветка UI:** «Начать».

После «Начать» — шаг 1, можно ходить.

---

### 1. Смотри и иди

**Цель:** Осмотрись. WASD — ходьба, мышь — взгляд.

> Горы с рудой рядом. Left Ctrl — бег, Space — прыжок.

**Подсветка мира:** ближайшие горные жилы, слабо, без типа.

**Готово:** сдвинулся ~8 м **или** повернул камеру ~90°.

---

### 2. Стройка

**Цель:** Нажми B — режим строительства.

> B включает стройку. Снизу выедет панель зданий.

**Подсветка UI:** подсказка B. После нажатия — пустой хотбар.

**Готово:** `isBuildMode == true`.

---

### 3. Хотбар из инвентаря

**Цель:** I — инвентарь. Перетащи Extractor, ленту и лабораторию на панель.

> I открывает все здания. Перетащи три карточки на слоты внизу. ПКМ с панели — убрать.

I работает только в стройке ([[PlayerInventory]]).

**Подсветка UI:** I → три карточки в сумке → пустые слоты хотбара по очереди.

**Готово:** на хотбаре есть extractor, conveyor, research_lab.

**Если застрял (~12 с):** пульс на карточке, которую ещё не перетащили.

---

### 4. Железная гора

**Цель:** Найди железную гору. Экстрактор — только на жилу.

> На горе один тип руды. Железо и медь — на вершинах, не на склоне. Зелёный призрак — клетка подходит. R крутит выход.

Железо и медь спавнятся на `MountainPeak` ([[WorldResourceScatterer.OreAllows]]). Экстрактор без жилы не ставится (`requiresResourceNode`).

**Подсветка мира:** жилы `iron_ore`. На призраке — стрелка выхода и свободная клетка перед ней.

**Готово:** ≥1 Extractor на `iron_ore`.

**Если застрял (~40 с):** пульс M. На карте — иконки железа. После карты снова жилы.

---

### 5. Три железа

**Цель:** Ещё два экстрактора на это же железо.

> Один качает медленно. Три — уже нормально. Выходы смотрят в одну сторону, не в скалу.

Интервал экстрактора ~1.5 с с множителем [[Economy.ExtractTimeMul]]. Три штуки — чтобы ожидание 125 руды не было пыткой.

**Подсветка мира:** свободные железные клетки. У стоящих — стрелка, если смотрит в гору.

**Готово:** ≥3 экстрактора на `iron_ore`.

---

### 6. Выделение и копия

**Цель:** Tab — рамка по трём экстракторам — C.

> Tab включает редактирование и берёт пустой слот (0). Если выбрать здание с панели — режим спадёт.
>
> Зажми ПКМ и обведи три экстрактора. C копирует группу.

Tab сам вызывает `SelectEmptyTool`. Если выбран слот здания, [[BuildSelectionController]] выходит из режима.

Не гейтим удаление и перенос. Одна фраза: Backspace сносит выделенное, M с выделением двигает группу (без выделения M — карта). Панель выделенных (O / [[SelectionActionsUI]]) не учим.

**Подсветка UI:** Tab, затем слот 0.

**Подсветка мира:** три железных экстрактора. Пока рамка не замкнута — пульс «обведи этих». После выделения — обводка группы и пульс C.

**Готово:** в буфере копии ≥3 Extractor.

**Если застрял:**
- не в Tab / не слот 0 — снова Tab;
- рамка пустая — не отпустил ПКМ над зданиями;
- выбрал экстрактор на хотбаре — режим сбросился, снова Tab.

Скопировал и сразу вставил на то же железо — шаг 6 уже готов, шаг 7 всё равно просит вставку **на медь**.

---

### 7. Вставка на медь

**Цель:** Дойди до горы Cooper ore. V — поставь копию на жилы.

> Соседняя гора — другая руда. V включает призрак группы. Наведи на медные жилы, ПКМ ставит. R крутит всю группу. Взгляд в сторону — отмена.
>
> Копия не ставится на траву: экстрактору нужна жила, как при ручной постановке.

Это и есть медные экстракторы. Руками ставить не просим. Вставка тратит монеты, как обычная постройка.

После C выделение сбрасывается — M снова карта, не перенос.

**Подсветка мира:** жилы `cooper_ore`. После V — зелёные клетки под призраком, если все на жилах.

**Подсветка UI:** V, затем подсказка ПКМ «подтвердить».

**Готово:** ≥2 экстрактора на `cooper_ore`.

**Если застрял (~40 с):** пульс M. На карте — медь. Призрак красный — сдвинь на жилы, не подтверждай.

**Если уже наставил медь руками:** шаги 6–7 пропускаются, если меди ≥2. Если меди нет, а копии нет — вернуть на шаг 6.

---

### 8. Лаборатория

**Цель:** Research Lab между двумя горами.

> Лаборатория принимает руду с ленты. На старте одна. Ставь на землю между горами, не на жилу.

Лимит: [[ResearchSystem.baseLabLimit]] = 1.

**Подсветка мира:** площадка между железным и медным кластером. На призраке — стрелка **входа**.

**Готово:** в мире есть лаборатория.

---

### 9. Запусти исследование — до лент

**Цель:** Печь уже активна сама. E / T — посмотреть дерево.

> Доступные исследования идут сами, сразу несколько. Печь уже считает руду. T — дерево с ходьбы.

**Готово:** узел `research_smelter` доступен или открыт.

**Если застрял (~15 с):** пульс E, если смотрит на лабу; иначе T.

---

### 10. Ленты

**Цель:** Довези железо и медь до лаборатории.

> Лента, зажми ПКМ и веди линию — углы сами. Выход экстрактора → лента → вход лаборатории. Две руды — в T перед лабой или с двух сторон.

Линия: зажал Place, повёл взгляд, отпустил. Форма (прямой / угол / T) сама по соседям ([[Conveyor]]).

**Подсветка мира:** выходы кластеров, вход лаборатории; если ленты сходятся — клетка T.

Экстрактор молчит — обводка и жила. Смотрит не в ленту — стрелка + R.

**Готово:** лаборатория приняла `iron_ore` и `cooper_ore` **в исследование**, не на продажу.

**Если счётчика нет, а руда едет:** исследование не запущено → шаг 9.

---

### 11. Ждём главу 1

**Цель:** Печь · Iron Ore x/140 · Cooper ore x/140

> Можно ставить ещё экстракторы — удобно копией. E по лаборатории — прогресс в её окне. Лишнее после исследования продастся.

Без новых окон. Цель в углу, пропуск (F1 всё / F2 шаг).

**Подсветка:** нет, пока не застрял. Руда не растёт ~45 с — снова выход / вход.

**Готово:** `research_smelter` завершён.

Награда узла: здание [[Smelter]]. Рецепты слитков ещё закрыты.

---

### 12. Плавильня

**Цель:** Поставь Smelter на железную линию.

> Печь закрыта. В инвентаре плавильня. Рецепт ещё закрыт — сначала исследование слитка. Плавильня врезается в ленту: руда входит, слиток выходит.

**Подсветка UI:** слот Smelter на хотбаре; если нет — I и карточка.

**Подсветка мира:** клетка на железной ленте. На призраке: вход со стороны экстракторов, выход дальше.

**Готово:** в мире есть Smelter.

Сборщик ещё не открыт.

---

### 13. Железный слиток

**Цель:** лаборатория → Железный слиток. 200 Iron Ore.

> В дереве открой «Железный слиток» и запусти. Нужно 200 Iron Ore в лабораторию.

**Подсветка UI:** `Res_research_iron_ingot`.

**Готово:** `research_iron_ingot` завершён.

---

### 14. UI здания — рецепт

**Цель:** E по плавильне → рецепт Iron Ingot.

> То же окно, что у лаборатории, только список рецептов. Нажми Iron Ingot. Без рецепта станок стоит.

[[CrafterBuilding]] без `currentRecipe` не крафтит.

**Подсветка мира:** плавильня.

**Подсветка UI:** карточка Iron Ingot.

**Готово:** у этой плавильни `currentRecipe == recipe_iron_ingot`.

---

### 15. Первая плавка

**Цель:** Пусть в плавильню зайдёт железная руда.

> Лента во вход плавильни. Когда пойдёт руда — появится слиток.

**Подсветка мира:** если руда не входит — экстрактор / лента / вход плавильни.

**Готово:** плавильня приняла ≥1 `iron_ore` **или** в буфере есть Iron Ingot.

Не ждём 125 слитков.

---

### 16. Медный слиток

**Цель:** лаборатория → Медный слиток. 200 Cooper ore.

**Подсветка UI:** `Res_research_cooper_ingot`.

**Готово:** `research_cooper_ingot` завершён.

---

### 17. Копия плавильни на медь

**Цель:** Скопируй плавильню на медную линию и поставь рецепт Cooper Ingot.

> Снова Tab, рамка по плавильне, C, V на медную ленту. E → Cooper Ingot.
>
> Так размножают заводы. Дальше так же: выделил — скопировал — вставил.

Короткий повтор шагов 6–7 и 13, не новый навык.

**Подсветка мира:** железная плавильня → медные жилы / медная лента.

**Подсветка UI:** Tab → C → V, затем карточка Cooper Ingot.

**Готово:** есть вторая плавильня на медной стороне **и** у неё рецепт `recipe_cooper_ingot`.

**Если медной ленты ещё нет:** сначала подсветка «протяни ленту с меди», потом вставка.

---

### 18. Отпуск

Панель. Обучение в этом мире выключается.

> Дальше — Сборщик: 350 Iron Ingot. Потом доски, пластины, стержни.
>
> Длинная цель — пройти всё дерево исследований, до последнего узла. Копией ускоряй линии, E — рецепты в станках.
>
> Побольше руды, побольше лент. Удачи.
>
> [Играть]

Дерево сами не открываем. После «Играть» подсветок нет.

## Дерево как дальняя цель (не шаги)

```
research_smelter          ← сделали в обучении (плавильня)
  research_iron_ingot     ← обучение
  research_cooper_ingot   ← обучение
    research_assembler    ← следующее, 350 Iron Ingot
      … доски, пластины, стержни, конструктор …
        research_ai_module ← конец дерева
```

Граф живой — [[ResearchSystem]] / [[ResearchTree]] / [[ResearchNodeData]]. Цены — лист «Стоимость лабы».

## Если игрок обогнал сценарий

Сделал шаг раньше — пропускаем. Медь руками без копии — 6–7 готовы, если меди ≥2 (копию всё равно покажем на плавильне, шаг 15). Исследование уже запущено — не возвращаем на E. Плавильня уже с рецептом — 13 готов. Две плавильни с нужными рецептами — 15 готов.

---

## Чего нет в обучении

Магазин, панель выделенных (O), апгрейд, шестерни, день/ночь, погода, океан, трубы, нефть, склад, обязательный сборщик, конструктор, вторая лаборатория, продажа руками, 125 слитков как гейт.

Перенос (M) и удаление (Backspace) — одна фраза на шаге 6, без отдельного гейта.

---

## Зачем так нарезано

- **I на шаге 3** — иначе нечем строить, если хотбар пустой.
- **Копия после трёх железа** — есть что копировать и зачем: вторая гора. Иначе медь ставят руками и Tab кажется лишним.
- **E на лаборатории до лент** — первое окно здания и защита от продажи руды.
- **E на плавильне** — то же окно, список рецептов.
- **Копия плавильни** — тот же жест на новом здании. К отпуску копия — привычка.
- **Отпуск на старте главы 2** — не водим за руку по 125 слиткам.
