# DataLocale — названия данных на языке интерфейса

**Файл:** `Assets/Script/Core/Data/DataLocale.cs`

Названия и описания зданий, предметов, рецептов и исследований по `id` (без учёта регистра и пробелов) для RU и EN ([[UiLocale]]). Пустая строка в таблице — берётся текст из ассета. Рецепт без своей строки берёт имя продукта (id без `recipe_`).

Код читает не `displayName` / `description`, а свойства **`Title`** / **`Info`** у [[BuildingData]], [[ItemData]], [[RecipeData]], [[ResearchNodeData]]. Новое здание или предмет: добавить строку в таблицу (или написать ассет сразу на русском и EN-строку в таблицу).

Жёстко прописанные подписи окон ([[MachineUI]], карточки стройки, хотбар, статистика, выделение) переведены на ключи `UiLocale`: `b.*`, `machine.*`, `unit.*`, `stats.*`, `hotbar.*`, `oil.rich_*`.
