# BuildGridVisualizer

**Файл:** `Assets/Script/Core/Player/BuildGridVisualizer.cs`

Рисует на земле клеточную сетку, когда включён режим стройки [[PlayerBuilder]]. Чтобы глаз видел, куда встанет здание.

Объект называется `BuildGridPlane`. Это Unity Plane (~25 клеток вокруг игрока), материал — [[RuntimeMaterials]] плюс текстура «рамка клетки / пустой центр».

Не влияет на логику, только картинка. Если шейдер непрозрачный, пустой центр (белый RGB, альфа 0) становится **сплошным белым квадратом** под ногами — это не туман.
