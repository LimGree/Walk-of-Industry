# Как открыть эту базу

Это не Word и не Google Docs. Это **хранилище заметок Obsidian**.

1. Установи [Obsidian](https://obsidian.md) (бесплатно).
2. Open folder as vault → укажи папку  
   `Walk of Industry/docs/vault`
3. Открой [[00_Index]] или [[Архитектура]].
4. Ссылки `[[GameManager]]` кликабельны. Граф (Graph view) покажет паутину классов.

Файлы обычный Markdown: их можно читать и в VS Code / GitHub, но паутина ссылок живёт именно в Obsidian.

Писать сюда можно руками — код игры от этого не меняется.
