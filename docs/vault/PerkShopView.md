# PerkShopView — вкладка «Снаряжение»

**Файл:** `Assets/Script/Core/UI/PerkShopView.cs`

Вкладка магазина [[WalletHud]] с плюшками [[PerkSystem]] за рубины. Вид как у декора ([[DecorShopView]]): чипы-фильтры по разделам (Передвижение, Работа, Экономика, Стиль), сетка плиток — иконка, название, уровень, цена, кнопка. Плитка с требованием (тройной прыжок ← двойной, скины ← вагонетка) закрыта, пока нет предка.

[[WalletHud]] умеет открыть магазин сразу на этой вкладке. Там же — обмен рубинов и монет **в обе стороны** (быстрые суммы + своё число; покупка рубина вдвое дороже продажи, чтобы обмен туда-обратно не давал прибыли — [[Economy]]).
