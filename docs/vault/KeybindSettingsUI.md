# KeybindSettingsUI

**Файл:** `Assets/Script/Core/UI/KeybindSettingsUI.cs`

Список клавиш: название действия, кнопка с текущей клавишей, сброс ↺.

Клик по клавише → [[KeybindStore.StartRebind]] → «нажмите новую». Конфликт (две функции на одной кнопке) подсвечивается классом `warn`.

Группы: движение, стройка, игра, система. Зум камеры в группе движения.

Режим `page: true` — без второго заголовка, встраивается во вкладку настроек.
