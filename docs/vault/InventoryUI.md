# InventoryUI

**Файл:** `Assets/Script/Core/UI/InventoryUI.cs`

«Сумка зданий» (не лут с лент). Сетка всех открытых построек, перетаскивание в хотбар, ПКМ убрать из слота.

Окно: шапка (название, счётчик, «I — закрыть»), фильтр-чипы по категориям (`IndustryUi.BuildingCategory`), сетка плиток **фиксированного размера** 118×150 (иконка, имя в 2 строки, цена, номер слота хотбара, цветная полоска категории), футер с подсказками ЛКМ/Тащи/ПКМ. Стили — секция `INVENTORY BAG` в `Industry.uss` (`Resources/UI`).

Блок ввода: пока сумка открыта, `InventoryUI.BlocksWorldMouse` глушит ЛКМ/ПКМ стройки ([[PlayerBuilder]]) и выделения ([[BuildSelectionController]]); колесо над окном (`PointerOverBag`) не листает хотбар ([[PlayerInventory]]).

Связи: [[PlayerInventory]], [[HotbarSlotView]], [[GameDatabase]].

Для сценария [[Обучение]] стартовый хотбар должен быть пустым: три здания только в сумке, игрок сам перетаскивает их на панель (I работает лишь в стройке).
