# MainMenu

**Файл:** `Assets/Script/Core/UI/MainMenu.cs`  
**Тип:** компонент на сцене главного меню

## Зачем нужен

Первый экран после запуска: логотип, список миров, создание мира, настройки, выход.

## Связи

- [[WorldCatalog]] — список и создание миров
- [[SettingsHub]] — экран настроек
- [[LoadingScreen]] — сцена `Loading`
- [[GameAudio]] · [[GameSettings]] · [[UiLocale]] · [[GameBranding]]

## Поля

Имена панелей UI Toolkit: `home`, `settings`, `worlds`, `create`, список миров, поле имени, какая вкладка настроек открыта.

Константы имён сцен: `SampleScene` (игра), `MainMenu`, `Loading`.

## Методы

### Awake
Снимает паузу времени, показывает курсор, включает музыку меню, применяет графику, строит UI. Подписывается на смену языка — тогда перестраивает весь экран (тексты на другом языке).

### LoadGame / LoadMenu
Статические «перейти в игру / вернуться в меню». `LoadMenu` ещё просит [[GameManager]] подчистить игровое состояние.

### BuildUi
С нуля рисует:

- **Home** — Continue / Миры / Настройки / Выход
- **Worlds** — карточки миров
- **Create** — имя нового мира
- **Settings** — [[SettingsHub]]

Потом открывает ту страницу, которая была открыта до пересборки (чтобы смена языка не кидала на главную).

### ShowHome / ShowWorlds / ShowCreate / ShowSettings / HideAll
Показать одну панель, спрятать остальные.

### PlayWorld
Помечает мир как активный в [[WorldCatalog]] и грузит сцену загрузки.

### CreateAndPlay
Создаёт запись мира и сразу запускает.

### RefreshWorldList
Читает диски, рисует карточки: имя, дата, сид, кнопки Играть / Удалить (удаление через [[UiModal]]).

### ContinueLatest
Берёт самый свежий мир. Если миров нет — форма создания.

### Quit
Закрывает игру. В редакторе Unity ещё останавливает Play Mode.
