# RoboticArm

**Файл:** `Assets/Script/Core/Buildings/RoboticArm.cs`  
**Предок:** [[BuildingBase]] + [[IInteractable]]

Рука: ворует предмет из здания сзади (буфер выхода или склад) и кладёт в здание спереди. Можно поставить **фильтр** — брать только выбранный [[ItemData]].

Не конвейер: ей не нужна лента между двумя соседними клетками, она переносит через воздух на 1 клетку.

UI фильтра — [[MachineUI]] (поиск по предметам). Сохранение: id фильтра и что в «руке».
