# BuildingPicker — СКМ «взять здание»

**Файл:** `Assets/Script/Core/Player/BuildingPicker.cs` (компонент на [[GameManager]]), действие `PickBuilding` в [[KeybindStore]] (по умолчанию СКМ, переназначается в настройках управления, группа «Стройка»).

Как «pick block» в Minecraft, работает везде:

- смотришь на здание и жмёшь СКМ — включается стройка ([[PlayerBuilder]]), тип здания попадает в хотбар, призрак получает поворот оригинала;
- **хотбар:** если здание уже там — выбирается его слот; иначе кладётся в текущий пустой слот, потом в первый пустой, иначе заменяет текущий;
- **Shift+СКМ** копирует ещё и настройки: рецепт станка, фильтр руки, ленты или станции дронов, «выход только спереди» у экстрактора. Их получают все следующие поставленные здания этого типа (`ApplyCopied` в `PlayerBuilder.SpawnAt`), пока не возьмёшь другое здание обычным СКМ;
- по жиле без здания — экстрактор, по воде — водокачка;
- здание 2-го уровня берётся как обычное (ставится 1-й уровень);
- любая лента → конвейер, труба → труба, вход или выход подземки → подземный конвейер;
- ещё не исследовано — тост «Ещё не исследовано: …», хотбар не меняется;
- отклик: звук, вспышка слота, тост с названием (и настройками при Shift).

Над хотбаром при любой смене выбранного здания на 4 с появляется «Название · ◈ цена» ([[InventoryUI]] `ShowSelectedLabel`).

Луч — `PlayerMovement.AimRaycast`, дальность с `ReachBonus` (3-е лицо).
