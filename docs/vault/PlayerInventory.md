# PlayerInventory

**Файл:** `Assets/Script/Core/Player/PlayerInventory.cs`

## Зачем нужен

Хотбар: несколько слотов с типами зданий. Это не инвентарь предметов с конвейера — предметы мира в карман игрока не кладутся. Сюда кладут **что строить**.

## Связи

[[BuildingData]] · [[GameDatabase]] · [[InventoryUI]] · [[HotbarSlotView]] · [[PlayerBuilder]] · [[KeybindStore]] (колёсико слотов) · [[SaveData]] (какие id лежат в слотах)

## Поля

Массив слотов, индекс выбранного, ссылка на строителя.

## Методы

- выбрать слот цифрой или колёсиком;
- положить/убрать здание в слот (из сумки перетаскиванием);
- отдать выбранное [[PlayerBuilder]];
- сохранить/загрузить список id для сейва.

Колёсико **без** зажатого зума меняет слот. С зажатым зумом колёсико меняет силу приближения камеры ([[PlayerMovement]]).
