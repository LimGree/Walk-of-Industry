# BlueprintLibraryUI

**Файл:** `Assets/Script/Core/UI/BlueprintLibraryUI.cs`

Окно библиотеки чертежей. P (действие `Blueprints`) только в режиме стройки. Esc закрывает.

Вкладки «этот мир / все миры», вид плитки или список, размер плиток крупный / средний / мелкий.

- Выделил здания → «Сохранить выделенное» + имя, иконка сверху пишется сама.
- Клик по карточке кладёт группу в буфер; вставка — обычный Ctrl+V / Place, за монеты как копия.
- Переименовать и удалить — через [[UiModal]].
