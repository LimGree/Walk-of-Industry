# DayNightCycle

**Файл:** `Assets/Script/Core/World/DayNightCycle.cs`  
**Тип:** компонент на [[GameManager]]

Каждый кадр двигает [[DayNight.Hour]], если в настройках включены сутки. Длина дня — слайдер минут реального времени на полный круг (по умолчанию 16). На паузе солнце стоит.

В инспекторе `previewHour` (0…24) и `previewDay` — крутить время сразу, не ждать реальные минуты. В Play слайдер ещё и показывает текущий час.

`LateUpdate` зовёт `GameSettings.ApplyAtmosphere()`: поворот света, цвет тумана, небо (диск солнца/луны, звёзды, закатная дымка), тинт земли. Событие `Changed` не шлёт — жилы из‑за этого не пересчитываются.

Сейв/загрузка через [[SaveSystem]]. Новый мир стартует около 07:25.
