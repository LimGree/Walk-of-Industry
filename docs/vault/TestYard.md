# TestYard

**Файл:** `Assets/Script/Core/World/TestYard.cs`

Тестовый двор для проверки зданий, стыков лент и жил.

## Как открыть

В главном меню зажать **Shift+Ctrl+Alt** и нажать **Продолжить**. Создаётся мир «ТЕСТ» (`WorldInfo.sandbox`), обучение выкл., много монет.

Повторный заход в тот же сейв двор не дублирует — ставится только если в сейве ещё нет зданий.

## Что ставит

- Музей лент: прямая, оба угла, T слева/справа, бока, тройник, разделитель, подземная пара, трубы + бак.
- Жилы iron / cooper / coal / stone / sand / sulfur / tree с экстрактором, лентой и складом.
- Сетка всех остальных зданий из [[GameDatabase]] (кроме лент/труб/подземки).
- Нефтекачалка; водокачка на ближайшем озере.

Игрок телепортируется к южному краю площадки, смотрит на север.
