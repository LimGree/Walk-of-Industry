# GoalsUI — HUD целей и журнал

**Файл:** `Assets/Script/Core/UI/GoalsUI.cs`

- Карточка текущей вехи [[GoalSystem]] с галочками по условиям.
- Отслеживаемая цепочка (если выбрана на [[ProductionMapUI]]).
- Карточка подсказки «в первый раз».
- **J** — журнал: все вехи + справочник прочитанных подсказок.
- Клик по условию или шагу цепочки — [[ProductionMapUI]] на нужном предмете.

Карточки не залезают на миникарту — [[HudAvoid]].
