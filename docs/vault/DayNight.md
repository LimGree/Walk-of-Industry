# DayNight

**Файл:** `Assets/Script/Core/World/DayNight.cs`  
**Тип:** статический

Часы мира `Hour` (0…24) и палитра неба: рассвет, день, золотой час, закат, сумерки, ночь. Солнце едет с востока на запад, ночью ту же лампу играет луна (холодный свет, не кромешная тьма — ленты читаются).

Ключевые часы: рассвет ~5:25, восход ~6:20, полдень 12, закат ~18:30, ночь после 21.

`Day` — номер суток (с 1). `Advance` крутит час и переносит день через полночь.

Часы на экране: `FormatClock` — только часы / часы:минуты / часы:минуты:секунды, опционально «День N». Вкл/формат в [[GameSettings]] и [[SettingsHub]].

Крутит время [[DayNightCycle]]. Красит картинку [[GameSettings.ApplyAtmosphere]]. В сейме: `worldHour`, `worldDay`.
