# MapSettings

**Файл:** `Assets/Script/Core/Map/MapSettings.cs`

PlayerPrefs миникарты и карты мира: круг/квадрат, угол экрана, зум, размер, прозрачность, компас, координаты, биом, сетка, голограммы, скрывать неисследованное, радиус исследования, **разрешать ли телепорт** (по умолчанию нет). Часы под картой — не здесь, а в [[GameSettings]] (`ClockVisible`), дубль-тумблер есть во вкладке миникарты.

Событие `Changed` — [[WorldMapUI]] сразу перекладывает рамку.

Не путать с [[GameSettings]] (графика) и [[MapSettingsUI]] (рисует слайдеры).
