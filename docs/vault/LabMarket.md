# LabMarket — цены сдачи в лабу

**Файл:** `Assets/Script/Core/Economy/LabMarket.cs` · вызывает [[ResearchSystem]] (`TrySubmitItem`) · показывает [[MachineUI]] (вкладка «Экономика»).

## Базовая цена — сложность производства

- Сырьё с жил — **0.2** монеты (5 штук = 1 монета).
- Переработанное: сколько сырья уходит на одну штуку (по рецептам из [[GameDatabase]], рекурсивно) × 0.2 × **(1 + глубина цепочки)**.
- Примеры: слиток железа 0.8 (было 2), стальной слиток 4.8, микросхема ≈ 59, квантовое ядро ≈ 554 (было 7). Крафт выгоднее сдачи руды, каждая ступень — наценка.
- Предмет без рецепта и не с жилы — по `item.sellValue` × 0.2.

## Насыщение рынка

- Каждая проданная штука копит «насыщение» предмета; оно спадает экспоненциально (τ = **120 с**) — если сдавать мало, цена восстанавливается.
- Цена вдвое ниже, когда предмета сдают примерно на **120 монет базовой цены в минуту** (у дешёвого порог — сотни штук, у дорогого — пара штук), но **не ниже 10%**.
- Одна гигантская линия упирается в потолок — выгоднее делать разное.
- Дробные монеты копятся, целые зачисляются. Насыщение не сохраняется: после загрузки мира рынок свободен (`Reset` из [[PlayerWallet]]).

Константы: `RawValue`, `FloorMultiplier`, `RecoverSeconds`, `HalfPriceCoinsPerMinute`.
