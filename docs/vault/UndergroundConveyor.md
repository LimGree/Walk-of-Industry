# UndergroundConveyor

**Файл:** `Assets/Script/Core/Buildings/UndergroundConveyor.cs`  
**Предок:** [[BuildingBase]]  
**Данные:** `underground_conveyor`

Подземный конвейер. В хотбаре один слот. Зажал постановку — тянешь **по прямой** — отпустил: ставится **вход и выход сразу**.

- Между ними максимум **5 пустых клеток** (вместе с концами — 7).
- Клетки между можно застраивать — груз идёт под землёй.
- Если выход не поставить (отпустил на той же клетке / отмена) — ничего не остаётся.
- Снос входа сносит выход и наоборот.
- Только твёрдые предметы.
- Вход принимает с ленты, чей `ExitDir` смотрит в его клетку. Выход толкает в клетку спереди.
- Сейв пишет `pair`/`exit` в extras и дублирует в `stateInt`/`stateFloat`. После загрузки `FinishLoad` склеивает пары по id и, если id потерялся, по лучу вперёд.
- Зазор: 5 клеток, исследование `research_underground_range_2` → 7, `research_underground_range_3` → 9. Линия обычного конвейера сама ставит вход/выход через занятые клетки, если подземка открыта.

Исследование `research_underground_conveyor` открывает и подземный конвейер, и [[Splitter]]. Узел `research_splitter` в дереве остаётся (нужен трубам/складам).
