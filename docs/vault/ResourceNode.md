# ResourceNode

**Файл:** `Assets/Script/Core/World/ResourceNode.cs`

## Зачем нужен

Жила в мире: «здесь железная руда», «здесь дерево». [[Extractor]] встаёт **на эту клетку** и кусает жилу.

## Поля

- `resource` — какой [[ItemData]]
- запас (если конечный) или бесконечность
- клетка на сетке

## Методы

- зарегистрироваться в клетке при появлении;
- `GetAt(клетка)` — статически найти жилу;
- `TryConsume` — отдать 1 единицу, если запас позволяет.

Расставляет их [[WorldResourceScatterer]] по биомам. Модели — [[ResourceNodePrefabs]].
