# SaveData

**Файл:** `Assets/Script/Core/Save/SaveData.cs`

Набор простых классов «как записать мир в JSON». Unity `JsonUtility` умеет только публичные поля, без словарей — поэтому списки пар ключ-значение.

Текущая версия файла: **8**.

## SaveData (корень)

Мир: имя, сид, позиция игрока, список зданий, исследования, хотбар, монеты/рубины, уровень лент, статистика, метки, битовая карта исследования, час суток `worldHour` (v6), номер дня `worldDay` (v7), погода `worldWeather` (v8), `extras` на вырост. Старые сейвы без часа стартуют в 09:00, день 1, ясно.

`Normalize` подставляет пустые списки, чтобы старый файл не падал.

## BuildingSaveData

Одно здание: id карточки, позиция, поворот, уровень, рецепт, прогресс, буферы, груз ленты, фильтр, `extras`.

## ResearchSaveData

Открытые id, текущий узел, сколько чего уже сдали.

## ItemAmountSave / BeltItemSave / SaveKeyValue / MapMarkerSave

Кирпичики списков: «предмет + число», «груз на ленте», «произвольная строка», «метка на карте» (клетка, имя, цвет, hidden).

## SaveItems

Статические переводчики словарь ↔ список для буферов.

Пишет/читает это всё [[SaveSystem]].
