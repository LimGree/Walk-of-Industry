# Splitter

**Файл:** `Assets/Script/Core/Buildings/splitter.cs` (имя файла с маленькой буквы — исторический артефакт)

**Предок:** [[BuildingBase]]

Разветвитель ленты: один вход (−Z), три выхода (+Z / ±X). Модель `splitter_model` доворачивается yaw 90°, сокеты всегда на краю клетки. Если выбранный выход забит, груз уходит в другие свободные стороны (round-robin). Выход с фильтром [[Conveyor]] не берёт чужой предмет: сплиттер сразу ищет другую сторону и не стопорит вход. Если передний груз не подходит фильтру, из очереди может выйти тот, который подходит. Visual передаётся ленте как у конвейера, иначе пул [[BeltItemView]] не гасит модель.

Здание открывается вместе с подземным конвейером (`research_underground_conveyor`). Тогда же появляется меню фильтра на ленте.

Нужен, когда одна лента кормит две машины.
