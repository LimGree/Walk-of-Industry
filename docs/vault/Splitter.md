# Splitter

**Файл:** `Assets/Script/Core/Buildings/splitter.cs` (имя файла с маленькой буквы — исторический артефакт)

**Предок:** [[BuildingBase]]

Разветвитель ленты: один вход (−Z), три выхода (+Z / ±X). Модель `splitter_model` доворачивается yaw 90°, сокеты всегда на краю клетки. Если выбранный выход забит, груз уходит в другие свободные стороны (round-robin). Visual передаётся ленте как у [[Conveyor]], иначе пул [[BeltItemView]] не гасит модель.

Здание открывается вместе с подземным конвейером (`research_underground_conveyor`).

Нужен, когда одна лента кормит две машины.
