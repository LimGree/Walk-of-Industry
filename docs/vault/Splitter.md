# Splitter

**Файл:** `Assets/Script/Core/Buildings/splitter.cs` (имя файла с маленькой буквы — исторический артефакт)

**Предок:** [[BuildingBase]]

Разветвитель ленты: один вход, несколько выходов. Предметы по очереди раскидывает по свободным направлениям (round-robin). Тик вместе с лентами в [[WorldSim]], груз — [[BeltItemView]].

Нужен, когда одна лента кормит две машины.
