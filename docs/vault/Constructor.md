# Constructor

**Файл:** `Assets/Script/Core/Buildings/Constructor.cs`  
**Предок:** [[CrafterBuilding]]

Конструктор деталей (шестерёнки, прутья, пластины). Логика крафта общая. Отличается префабом, списком рецептов (`allowedBuildingIds` у [[RecipeData]]) и звуком/моделью.

См. [[Assembler]] — тот же паттерн апгрейда визуала.
