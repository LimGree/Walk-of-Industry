# WeatherCycle

**Файл:** `Assets/Script/Core/World/WeatherCycle.cs`  
**Тип:** компонент на [[GameManager]]

Частицы дождя вокруг камеры (не на весь остров). Гроза: вспышка неба + гром с задержкой. Инспектор `previewWeather` — переключить сразу.

Автосмена, если включена: каждые 3–7 минут случайно ясно / дождь / гроза (может выпасть то же самое). Сейв: `worldWeather`.
