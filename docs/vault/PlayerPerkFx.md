# PlayerPerkFx — видимые плюшки

**Файлы:** `Assets/Script/Core/Player/PlayerPerkFx.cs`, `Player/CartVisual.cs`

## PlayerPerkFx

То, что из [[PerkSystem]] видно на персонаже:

- **След на бегу** — искры / пар / листья (`trail_*`).
- **Крылья** над головой при планировании, с расцветкой (`wings_stripes`, `wings_sunset`).
- **Дрон-компаньон** (`pet`) за плечом: ночью светит и показывает на ближайший сломанный или простаивающий станок в 80 клетках.

## CartVisual

Вагонетка под игроком, пока он едет по ленте ([[BeltRide]]). Собирается из кубов, цвет — `cart_copper` / `cart_gold` / `cart_steam`. Отдельный объект в мире (не дочерний игроку): стоит по ходу ленты и не крутится за камерой.
