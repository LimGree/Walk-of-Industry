# BuildingBase

**Файл:** `Assets/Script/Core/Buildings/BuildingBase.cs`  
**Тип:** абстрактный предок (сам по себе на сцену не ставят)

## Зачем нужен

Общие правила любого здания:

- занять клетки сетки;
- иметь входы и выходы ([[BuildingSocket]]);
- уметь принять предмет или отдать его соседу;
- иметь маленький буфер, если сосед занят;
- сохранять уровень и внутренности.

Все станки, ленты, склады **наследуют** этот класс.

Добыча, ленты и лаба **не останавливаются** вдали. За радиусом [[GameSettings.RenderDistance]] гасятся только модельки и коллайдеры ([[WorldView]]); при входе в зону они снова включаются.

## Поля

| Поле | Роль |
|---|---|
| `data` | Карточка из каталога (имя, цена, размер) |
| `inputSockets` / `outputSockets` | Массивы розеток |
| `maxOutputBuffer` | Сколько штук можно скопить на выходе |
| `outputBuffer` | Очередь предметов, которые ещё не уехали |

`FootprintSize` — размер в клетках с учётом поворота.

## Методы

### OnPlaced
Здание только что поставили. Регистрирует клетки. Просит [[BuildingLinker]] соединить соседей.

### OnRemoved
Перед сносом: запомнить соседей, отключить розетки, освободить клетки, пересоединить соседей без этого здания.

### OnRotated
Пересоединить вокруг.

### ReRegisterOnGrid / RegisterOnGrid
Снять со старых клеток, занять новые (после переноса/поворота).

### TryReceiveItem
По умолчанию «нет, не беру». Дети переопределяют: склад берёт всё, крафтер — только ингредиенты рецепта.

### CanAcceptFrom
Можно ли принять от этого соседа? Только если он стоит со стороны **входа**.

### HasOutputSpace / TryStealFromOutput / TryReturnToOutput
Буфер выхода: есть место? рука может украсть передний предмет? вернуть, если не удалось забрать.

### TryOutputToAny
Попытаться запихнуть предмет во все выходы. Не вышло — в буфер. Буфер полон — провал.

### TryPushToConnections
Для каждого выходного сокета: есть провод к чужому входу? или здание прямо в клетке перед сокетом? Тогда `TryReceiveItem`.

### FlushOutputBuffer
Пока буфер не пуст, пытаться вытолкнуть передний предмет.

### ReadLevel / ApplyLevel / CanUpgradeBuilding / TryUpgradeBuilding
Уровень 1 по умолчанию, апгрейд выключен. Экстрактор и сборщик переопределяют.

### WriteSave / ReadSave
База пишет мало. Дети дописывают рецепт, буферы, фильтр руки и т.д.
