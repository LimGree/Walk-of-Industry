# Папки и ассеты без своего C#-класса

Код — не вся игра. Ниже то, что лежит рядом и тоже важно.

## Структура `Assets/`

| Папка | Что внутри |
|---|---|
| `Art/Icons/` | `Buildings` (иконки зданий, `gen/` — из генератора), `Items`, `Research`, `Misc` (монета, рубин) |
| `Art/Models/` | `Buildings` (генератор `generated/source/*.py` и копии OBJ для Blender), `Items` (FBX предметов), `Nodes` (FBX жил) |
| `Art/Animations/Buildings/` | контроллеры и клипы зданий ([[BuildingFx]]); `BUILD_VERSION.txt` — маркер сборщика, **не удалять** |
| `Art/Materials/`, `Art/Terrain/` | прочие материалы, террейн мира |
| `Prefabs/` | `Buildings` (здания), `Nodes` (жилы) |
| `Data/` | `Buildings`, `Items`, `Recipes`, `Research` — карточки ScriptableObject |
| `Resources/` | всё, что код грузит **по пути**: модели `Models/`, декорации `Decor/`, UI, звук, FX, шейдеры. Не переименовывать файлы внутри |
| `Input/` | таблица клавиш и сгенерированный класс |
| `Scenes/`, `Script/`, `Editor/`, `TextMesh Pro/` | как раньше |

Переносить ассеты — только вместе с `.meta` (или в Unity): ссылки держатся на GUID.

`_unused_assets/` в корне проекта (вне Assets) — карантин неиспользуемого (старые иконки, второй UI, лишние террейны, стрелки I/O). Unity его не видит; вернуть — перенести обратно вместе с `.meta`.

## Сцены (`Assets/Scenes/`)

- `MainMenu.unity` — меню
- `Loading.unity` — загрузка
- `SampleScene.unity` — игровой мир
- `3dmodeling.unity` — служебная сцена для моделей, в билд обычно не кладут

## Данные (`Assets/Data/`)

Папки `Buildings`, `Items`, `Recipes`, `Research` — сотни `.asset`. Это экземпляры [[BuildingData]], [[ItemData]], [[RecipeData]], [[ResearchNodeData]]. Каталог-указатель: `Resources/GameDatabase.asset`.

## Скрипты (`Assets/Script/Core/`)

Не свалка. Папки:

| Папка | Что внутри |

| `Economy/` | [[Economy]], кошелёк, статистика |
| `Editor/` | только редактор (footprint) |
| `Grid/` | сетка, footprint, occupancy |
| `Items/` | стек и экземпляр предмета |
| `Logistics/` | конвейер, труба, линкер, скорость лент |
| `Map/` | исследование, метки, настройки карты |
| `Player/` | ходьба, стройка, сетка/стрелки |
| `Research/` | [[ResearchSystem]] |
| `Save/` | JSON мира |
| `Settings/` | графика, клавиши |
| `UI/` | меню, HUD, карты |
| `World/` | биомы, жилы, сутки, погода, scatterer |

`GameManager.cs` — в корне Core. Сборщик Windows — `Assets/Editor/AlphaBuild.cs`.

## Модели и префабы

- `Assets/Art/Models/` — FBX предметов и жил, генератор моделей зданий
- `Assets/Prefabs/Buildings/` — готовые объекты зданий, которые ставятся в мир
- Конвейер: живой `Conveyor_01`; формы `Conveyor_Corner`, `Conveyor_Tee` (T 4/5), `Conveyor_Sides` (два бока), `Conveyor_Triple` (три входа)
- `Assets/Art/Icons/` — иконки HUD, предметов, исследований

## UI Toolkit

- `Assets/Resources/UI/` — единственная копия стилей (uss, tss, шрифт, uxml); второй копии `Assets/UI Toolkit/` больше нет. Описание дизайн-системы — `docs/UI_Toolkit_README.md`

## Звук

`Assets/Resources/Audio/` — папки `ui`, `world`, `buildings`, `music`, `ambient`, `player`. Имена файлов = ключи в [[GameAudio]]. Дождь: `ambient/amb_rain`, гром: `world/world_thunder` (Mixkit, `weather-credits.txt`).

## Шейдеры

- `WalkToBiomeUnlit` — unlit с альфой и опциональным туманом по UV; оверлей биомов, сетка, призраки, голограммы
- `WalkToBiomeSky` — градиентное небо под слайдеры света/тумана [[GameSettings]]
- `WalkToBiomeInvert` — инверт прицела

## Input

`Input/InputSystem_Actions.inputactions` — таблица клавиш, см. [[InputSystem_Actions]].

## Чего в git быть не должно

Папка `Library/` — кэш Unity, сотни мегабайт. В репозиторий не кладут.

## Сейвы игрока

Не в проекте, а в AppData: `.../persistentDataPath/worlds/<id>/save.json`. См. [[WorldCatalog]].
