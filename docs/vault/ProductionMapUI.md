# ProductionMapUI — карта производства (K)

**Файл:** `Assets/Script/Core/UI/ProductionMapUI.cs`. Данные — [[ProductionGraph]].

- **Слева** — граф по ступеням (сырьё → … → ИИ-модуль). У выбранного предмета подсвечены ингредиенты и потребители, есть поиск.
- **Справа:**
  - «Как сделать» — цепочка до руды с числом станков на выбранную скорость (предметов в минуту);
  - «Как подключить» — схема станка сверху: зелёные стрелки — входы, оранжевая — выход, синие — трубы. Стороны по правилу [[BuildingPrefabLayout]] (выход спереди, вход сзади, второй вход справа; у конструктора оба входа сзади);
  - «Где используется».
- Отслеживание предмета — цепочка в HUD [[GoalsUI]].

Открывается на K, из [[ResearchTree]] («из чего делать цену»), из [[GoalsUI]] и с финальной карточки обучения ([[TutorialSystem]]).
