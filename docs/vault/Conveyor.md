# Conveyor

**Файл:** `Assets/Script/Core/Logistics/Conveyor.cs`  
**Предок:** [[BuildingBase]]  
**Правила:** [[BeltRules]]

## Зачем нужен

Лента 1×1. Выход всегда спереди (`transform.forward` → `ExitDir`). Форму игрок не выбирает: маска входов из соседей, чей **выход** кормит эту клетку.

Один объект, меш формы **создаётся только для текущей** (угол/T/бока/тройник не висят выключенными). Груз — пул моделей [[BeltItemView]]. Тик всех лент — [[WorldSim]], не `Update` на каждой. Сокетов на ленте нет.

| Входы относительно ExitDir | Форма | Префаб |
|---|---|---|
| нет / только зад | Straight | `prefab` |
| один бок | Corner (лево/право) | `cornerPrefab` |
| зад + один бок | Tee | `teePrefab`; левый рукав меняет материал стрелок (`teeMirrorMaterial`), меш не зеркалится |
| оба бока | Sides | `sidesPrefab` |
| зад + оба бока | Triple | `triplePrefab` |

После place/remove/rotate — worklist 3×3, снапшот маски ([[BuildingLinker]]).

Фильтр предмета (меню в режиме строительства): чужое не заезжает, стрелки красятся в цвет номенклатуры. Копия тащит фильтр.

Линия смотрят по оси жеста. Smart yaw только у одиночного куска и только если текущий поворот никуда не кормит, а соседний вход ровно один. Если подземный конвейер уже открыт и жест пересекает занятые клетки, в разрыв ставится пара входа/выхода (зазор ≤ 5). Призраки (одиночный, линия, копия) считают маску через `Conveyor.PreviewExits`. Стоящая лента, в которую смотрит гост, на превью тоже меняет форму (`ShowIncomingVisual`), симуляция груза не трогается.

Сдача дальше: клетка `Cell + ExitDir`. Станок принимает, если его вход смотрит на ленту.

На T / боках / тройнике входы чередуются (главная, боковая, главная…). Плотная главная лента не запирает смежную: слот на перекрёстке отдаётся по очереди.

Стрелки I/O в режиме стройки: на прямой и углу только незакрытый край; на T / боках / тройнике — на самой клетке перекрёстка.
