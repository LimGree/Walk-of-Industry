# RuntimeMaterials

**Файл:** `Assets/Script/Core/World/RuntimeMaterials.cs`

Unity в билде выкидывает неиспользуемые шейдеры. `Shader.Find("Unlit/Color")` внезапно возвращает null — розовые объекты.

Этот класс грузит свой шейдер из Resources (`WalkToBiomeUnlit`) и выдаёт материал с цветом/текстурой.

Им пользуются: оверлей биомов [[WorldBiomeMap]], сетка стройки [[BuildGridVisualizer]], призраки, кубики на ленте, голограммы меток.

`ApplyWorldGfx` пишет `_WalkLightTint` с текущего [[GameSettings]], чтобы земля и сетка тускнели вместе со слайдером света.

Шейдер умеет альфу: пиксели с `a < 0.01` выкидываются (`clip`). Иначе сетка стройки рисовалась сплошным белым квадратом — внутри текстуры RGB белый, альфа 0, а блендинга не было.
