Отмечай `[x]` по ходу. Если пункт не прошёл — запиши рядом, что увидел (скрин/текст из консоли), и пришли мне.

Консоль разработчика — клавиша `` ` `` (ё). Полезные команды:

## 3. Станки: авторецепт и причины простоя

- [ ] Сборщик/плавильня с **одним** доступным рецептом при постройке сразу получает рецепт
- [ ] Станок с несколькими рецептами берёт рецепт по **первому пришедшему** предмету (если подходит ровно один)
- [ ] Настройки → «Авторецепт» выкл → станки рецепт сами не выбирают
- [ ] НПЗ рецепт по предмету **не** выбирает (так задумано), при постройке с одним рецептом — выбирает
- [ ] Над стоящим станком (через ~5 с) «!» и **подпись** под ним:
  - [ ] без рецепта — «нет рецепта — E»
  - [ ] нет ингредиента — «ждёт: <предмет>»
  - [ ] пришёл не тот предмет (лента встала) — «не тот предмет: <предмет>»
  - [ ] выход забит — «выход забит»
- [ ] Лаборатория → вкладка «Простой» — те же тексты причин
- [ ] Подпись читается (не кракозябры, не розовый квадрат), смотрит в камеру

## 4. Дерево исследований

## 5. Модели зданий

- [ ] **Конструктор**: на корпусе два люка — сзади и справа — с зелёными стрелками; над плашками входов цифры **1** и **2**
- [ ] Цифры видны и на **призраке** при постройке
- [ ] **Химзавод**: сзади люк для ленты, слева синий патрубок трубы; плашки портов на месте (и на призраке)
- [ ] **НПЗ**: с обеих сторон люк + патрубок; при смене рецепта на серную кислоту плашки портов меняются (вход — лента, выход — труба)
- [ ] Цвета плашек везде: вход — **зелёная** стрелка, выход — **оранжевая**, труба — **синее** кольцо
- [ ] Поворот зданий на 90/180/270 — люки и плашки поворачиваются вместе с сокетами
- [ ] Иконки в меню стройки обновились; у Конструктора иконка сзади-справа, видно оба люка
- [ ] Остальные модели (плавильня, сборщик, экстрактор, склад, лаборатория) не сломались

## 6. Карта производства (K)

- [ ] K открывает/закрывает окно; Esc закрывает
- [ ] Слева столбцы «СЫРЬЁ», «СТУПЕНЬ 1…7»; у плитки — иконка, имя, станок
- [ ] Закрытое — бледное с замком; уже производимое — зелёная полоска слева
- [ ] Клик по плитке: ингредиенты подсвечены голубым, потребители — оранжевым, **стрелки** между ними
- [ ] Поиск по имени фильтрует плитки
- [ ] «Скрыть закрытое» работает и запоминается
- [ ] Скорость 10/30/60/120 — пересчитывает число станков в «Как сделать»
- [ ] «Как сделать»: дерево до руды, у каждой строки «станок ×N», у сырья «жила в N м» + кнопка «На карте»
- [ ] «На карте» → ставит метку на ближайшую жилу и открывает карту мира; метка видна в мире
- [ ] Для закрытого предмета — «Нужно исследование: …» и кнопка «В дереве исследований» → открывает лабораторию на этом узле
- [ ] «Как подключить»: квадрат станка, входы/выходы с подписями ингредиентов; у Конструктора два входа (сзади и справа) + заметка «в любой вход»; у Химзавода синий вход трубы
- [ ] «Где используется» — клик по предмету переключает карту на него
- [ ] Справочник рецептов (лаборатория → «Рецепты») — кнопка «На карте производства»
- [ ] Окно нормально выглядит на 1920×1080 и на меньшем разрешении (нет обрезанных кнопок)
